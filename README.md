# 🚀 WAREX Enterprise

> **Building the Future of Smart Warehouses.**

WAREX Enterprise is a **3D Warehouse Digital Twin** built using **C++, Data Structures, Object-Oriented Programming, Three.js, and modern web technologies**.

The project combines an enterprise-grade warehouse management system with an interactive 3D visualization platform.

---

## ✨ Features

- 📦 Smart Inventory Management
- 🌐 Interactive 3D Warehouse
- ⚡ C++ Backend
- 🧩 Object-Oriented Architecture
- 📚 Manual Data Structures Implementation
- 🔌 REST API Integration
- 🎥 Animated Warehouse Navigation

---

## 🛠 Tech Stack

| Layer | Technology |
|--------|------------|
| Frontend | HTML, CSS, JavaScript |
| 3D Engine | Three.js |
| Backend | C++ |
| API | Crow Framework |
| Build System | CMake |
| Version Control | Git + GitHub |
